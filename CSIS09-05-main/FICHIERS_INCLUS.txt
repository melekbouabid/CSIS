2. FICHIERS DE MODÈLES (joblib)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🤖 risk_model.joblib (82 MB)
     - Modèle RandomForest binaire entraîné
     - Prédit le risque futur criminel (probabilité)
     - 300 arbres de décision
     - Seuil décision: > 20%
     → Utilisé par predict_risk()

  🤖 crime_type_model.joblib (275 MB)
     - Modèle RandomForest multiclasses entraîné
     - Prédit le type de crime spécifique
     - 21 classes de crimes possibles
     - Entraîné sur cas avec antécédent criminel
     → Utilisé si risque > 20%

🚀 DÉMARRAGE RAPIDE (5 MINUTES)
================================================================================

1. Ouvrir PowerShell dans le dossier Downloads

2. Créer l'environnement:
   python -m venv .venv_crime

3. Activer l'environnement:
   .\.venv_crime\Scripts\Activate.ps1

4. Installer les dépendances:
   pip install -r requirements.txt

5. Lancer la démo:
   python demo_predict_risk.py

6. Vous verrez 4 exemples de prédictions réussies!
